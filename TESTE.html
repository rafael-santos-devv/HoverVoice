📝 Testando Narração de Texto

Este é um parágrafo de teste. Passe o mouse sobre este texto para ouvir a extensão HoverVoice narrar o conteúdo. Esta é uma ferramenta de acessibilidade poderosa para pessoas com deficiência visual.

Você pode passar o mouse sobre qualquer elemento desta página: parágrafos, títulos, botões, links, imagens e até formulários. A extensão lerá tudo para você.

💡 Dicas para Melhor Experiência

  • Certifique-se de que a extensão está ativada no popup
  • Use Alt + A para ativar/desativar rapidamente
  • Ajuste a velocidade nas configurações de voz
  • Passe o mouse lentamente sobre os elementos
  • Se não ouve nada, verifique o volume do seu dispositivo
  • Teste usando o botão "Ouvir" no popup da extensão
