# 🎙️ HoverVoice - Início Rápido

Bem-vindo ao **HoverVoice**! Uma extensão de acessibilidade que torna a internet mais acessível para pessoas com deficiência visual.

## ⚡ Início Rápido (30 segundos)

### 1️⃣ Instale a Extensão
```
1. Abra: chrome://extensions/ (Chrome) ou edge://extensions/ (Edge)
2. Ative: "Modo de desenvolvedor" (canto superior direito)
3. Clique: "Carregar extensão sem empacotamento"
4. Selecione: A pasta HoverVoice
```

### 2️⃣ Ative a Extensão
- Clique no ícone azul com olho na barra de ferramentas
- Alterne o switch "HoverVoice" para ATIVO
- Você verá: "HoverVoice Ativo - Passe o mouse para ouvir"

### 3️⃣ Use!
- **Passe o mouse** sobre qualquer elemento e ele será narrado
- **Pressione Alt+A** para ativar/desativar rapidamente
- **Use Tab** para navegar pelos elementos

## 🔧 Precisa de Ajuda?

### A extensão não funciona
1. Verifique em `chrome://extensions/` se está **habilitada**
2. **Recarregue** a página (Ctrl+R)
3. Certifique-se de que **JavaScript está ativado**

### Não ouve áudio
1. Verifique o **volume do navegador**
2. Verifique o **volume do sistema**
3. Teste com o botão **"Ouvir"** no popup

### Elementos não são narrados
1. Ative a extensão
2. **Recarregue a página**
3. Passe o mouse sobre **elementos com texto**
