📦 Guia de Instalação

Siga os passos abaixo para instalar a extensão HoverVoice no seu navegador:

Para Google Chrome:

  1. Abra o Chrome e digite na barra de endereço: chrome://extensions/
  2. Ative o "Modo de desenvolvedor" no canto superior direito
  3. Clique no botão "Carregar extensão sem empacotamento"
  4. Navegue até a pasta do HoverVoice e selecione-a
  5. Pronto! A extensão será carregada e o ícone aparecerá na barra de ferramentas

Para Microsoft Edge:

  1. Abra o Edge e digite na barra de endereço: edge://extensions/
  2. Ative o "Modo de desenvolvedor" no canto inferior esquerdo
  3. Clique em "Carregar extensão descompactada"
  4. Selecione a pasta do HoverVoice
  5. A extensão estará pronta para usar!
✅ Instalação concluída! Agora você pode usar o HoverVoice em qualquer site.

✨ Recursos Principais

🖱️ Narração ao Hover

Passe o mouse sobre qualquer elemento para ouvir seu conteúdo narrado automaticamente.

⌨️ Atalhos de Teclado

Alt+A para ativar/desativar. Tab para navegar entre elementos.

🎚️ Configurações Avançadas

Ajuste velocidade, tom e volume da voz conforme sua preferência.

📝 Testar Voz

Digite um texto qualquer e clique em "Ouvir" para testar a narração.

🌐 Funciona em Todo Site

Compatível com todos os sites e plataformas web.

💾 Memória de Configurações

Suas preferências são salvas automaticamente.

🎯 Como Usar

1. Ativar a Extensão

  1. Clique no ícone da extensão (olho azul) na barra de ferramentas
  2. Ative o switch "HoverVoice"
  3. Você verá a mensagem: "HoverVoice Ativo - Passe o mouse para ouvir"

2. Usar na Página

  1. Simplesmente passe o mouse sobre qualquer texto, botão, link ou imagem
  2. A extensão lerá o conteúdo automaticamente
  3. Use Tab para navegar pelos elementos

3. Configurar a Voz

  1. Abra o popup da extensão
  2. Clique em "Configurações de Voz"
  3. Ajuste os controles de velocidade, tom e volume
  4. As mudanças são salvas automaticamente

4. Testar

  1. No popup, digite um texto no campo "TESTAR VOZ"
  2. Clique no botão "Ouvir"
  3. Teste suas configurações antes de usar no site

⌨️ Atalhos de Teclado

Atalho Ação
Alt + A Ativa ou desativa a extensão
Tab Navega para o próximo elemento
Shift + Tab Navega para o elemento anterior

📋 Elementos Narrados

O HoverVoice narração os seguintes tipos de conteúdo:

  • ✓ Texto de parágrafos
  • ✓ Títulos e subtítulos
  • ✓ Botões e links
  • ✓ Descrição alternativa de imagens (atributo alt)
  • ✓ Rótulos de formulários (label)
  • ✓ Valores de inputs
  • ✓ Itens de lista
  • ✓ Células de tabela

🔧 Solução de Problemas

A extensão não funciona

Solução: Verifique se a extensão está ativada em chrome://extensions/. Se estiver desativada, clique para ativar.

Não consigo ouvir o áudio

Solução:
  • Verifique o volume do navegador
  • Verifique o volume do sistema
  • Teste usando o botão "Ouvir" no popup
  • Verifique se há fones de ouvido ou caixas conectadas

Os elementos não são narrados

Solução:
  • Certifique-se de que a extensão está ativada
  • Recarregue a página (Ctrl + R ou Cmd + R)
  • Passe o mouse sobre elementos com texto

A voz está muito rápida ou muito lenta

Solução: Abra o popup da extensão e ajuste o controle de "Velocidade" na seção de configurações.
⚠️ Nota: Alguns navegadores podem ter suporte limitado a idiomas ou síntese de voz. Certifique-se de que seu navegador suporta o Português Brasileiro.

💻 Requisitos do Sistema

  • ✓ Google Chrome v90+ ou Microsoft Edge v90+
  • ✓ JavaScript habilitado
  • ✓ Acesso a áudio/fones de ouvido
  • ✓ Suporte a Web Speech API (nativa)

💡 Dicas Úteis

🎯 Dica 1: Use Alt + A para ativar/desativar rapidamente sem abrir o popup.
🎯 Dica 2: Configure a velocidade em 1.5x ou 2x para melhor compreensão.
🎯 Dica 3: Use Tab para navegar pelos elementos da página de forma sequencial.
🎯 Dica 4: O botão "Ouvir" é perfeito para testar suas configurações de voz antes de usar no site.
🎯 Dica 5: Certifique-se de que os atributos alt estão preenchidos nas imagens para uma melhor experiência.
